# Week 4 Decision Guide

| AWS Service | Use this when… |
|---|---|
| **Amazon S3** | You need scalable object storage for files, images, backups, or datasets. |
| **Amazon EBS** | You need persistent block storage attached to an EC2 instance. |
| **Amazon EFS** | Multiple EC2 instances need shared file storage. |
| **Amazon RDS** | You need a managed relational database using SQL. |
| **Amazon DynamoDB** | You need a managed NoSQL database for fast, scalable key-value or document lookups. |
