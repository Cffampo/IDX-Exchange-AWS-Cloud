# Week 1 - Cloud Fundamentals & Account Setup

The AWS root user has full access to an AWS account and should only be used for tasks that require root access. For everyday AWS work, I created an IAM user so that I can manage AWS resources without using the root account. IAM allows AWS accounts to control who has access to resources and what actions they are allowed to perform. The Shared Responsibility Model means that AWS and the customer are both responsible for security, but for different parts of the environment. AWS is responsible for securing the underlying cloud infrastructure, including the hardware, networking, and facilities that run AWS services. As the customer, I am responsible for securing the resources and data that I put in AWS, including managing permissions and credentials. Using MFA, IAM users, and budget alerts helps protect the account and avoid unexpected AWS costs.
